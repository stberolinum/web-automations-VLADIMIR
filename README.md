# web-automations-VLADIMIR

Веб-автоматизации, размещённые на GitHub.

## Структура

- `docs/` — веб-страницы, публикуются через GitHub Pages:
  https://stberolinum.github.io/web-automations-VLADIMIR/
- `scripts/` — скрипты автоматизаций.
- `.github/workflows/` — запуск скриптов через GitHub Actions (по расписанию или вручную).

## Секреты

Пароли и API-ключи не хранить в коде — только в
Settings → Secrets and variables → Actions.
